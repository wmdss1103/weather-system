# 天气系统 · 全国城市天气 + 3D 天气实景

一个纯前端网页项目：查询全国城市天气、查看逐小时降雨趋势，并用三维场景演示晴、多云、雾、雨、雪等天气效果。

## 功能

- **地点选择**：省 → 市 → 区县三级联动，覆盖全国城市
- **天气查询**：温度、体感温度、湿度、风速、降水与天气描述
- **降雨曲线**：当天 00:00 至次日 00:00 共 25 个时点，支持拖动、播放与手动模拟
- **3D 场景**：程序生成的三维城市，晴 / 多云 / 雾 / 雨 / 雪 可切换
- **视角操作**：旋转、缩放、平移、自动环绕，日夜与灯光色温预览

## 技术实现

| 部分 | 技术 |
|---|---|
| 页面 | HTML + CSS + 原生 JavaScript（无框架） |
| 天气数据 | [Open-Meteo API](https://open-meteo.com/)（浏览器直接请求，每 15 分钟自动刷新） |
| 三维渲染 | 原生 WebGL + GLSL 着色器（WebGL 不可用时自动降级 Canvas 绘制） |
| 二维图表 | Canvas 2D（天空、降雨曲线、时间轴） |
| 地点目录 | 和风天气公开城市列表（China-City-List） |

> 本项目未搭建独立后端、未使用数据库，属于"前端 + 第三方天气接口"架构。

## 如何运行

1. 把 `index.html` 和 `locations.js` 放在**同一个文件夹**
2. 用 Edge 或 Chrome 打开 `index.html` 即可，无需安装任何环境
3. 联网时自动获取实时天气；断网时主界面仍可运行（使用已缓存数据或手动模拟）

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构、样式、天气请求与三维渲染逻辑 |
| `locations.js` | 全国省、市、区县地点目录（名称、ID、经纬度） |

## 说明

- 降雨数据来自模型估算 / 预报，不是雨量站实测数据
- 三维城市为程序生成的示意场景，不代表所选城市的真实建筑
- 手动编辑的降雨曲线仅本次页面有效，刷新后恢复联网数据
